## 📦 Instalasi

### 🐧 Termux / Linux / Mac

**1. Update & upgrade sistem**
```bash
pkg update && pkg upgrade -y
```

**2. Install Python & pip**
```bash
pkg install python python-pip -y
```

**3. Install git (opsional)**
```bash
pkg install git -y
```

**4. Clone repository**
```bash
git clone https://github.com/zevxxddos-collab/ZevxxSpammerotp
```

**5. Masuk ke folder**
```bash
cd ZevxxSpammerotp
```

**6. Install dependencies**
```bash
pip install -r requirements.txt
```

**7. Jalankan tools**
```bash
python otpzevxxspam.py
```
